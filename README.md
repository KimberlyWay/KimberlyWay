## 🟣 Обо мне

Специализируюсь на администрировании **Linux (Ubuntu)**, контейнеризации и проектировании защищённых сетевых архитектур. Фокус — на оптимизации сетевого стека, приватности и автоматизации инфраструктуры.

<br>

## 🌐 Собственный проект (практический опыт)

Разработала и поддерживаю VPN-сервис **VPN Wisp** — полный цикл, от инфраструктуры до продаж:

| | |
|---|---|
| 🌐 **Сайт-визитка** | [WISP Hub](https://mywisp.uk/) |
| 🤖 **Telegram-бот** для управления подпиской и подключением | [WISP Bot](https://t.me/vpnwispbot) |
| 🛒 **Веб-магазин** (self-service подключение и оплата) | [WISP Store](https://shop.mywisp.uk/) |
| 📊 **Публичный статус серверов** | [Uptime Kuma](https://kuma.mywisp.uk/status/wisp) |

Проект охватывает: VLESS/Reality на нескольких VPS в разных регионах, Cloudflare (DNS, CDN, Tunnel), реверс-прокси, автоматизацию выпуска SSL, Telegram-бота как интерфейс управления клиентами и мониторинг аптайма.

### Оптимизация сети (sysctl)
![sysctl](https://img.shields.io/badge/sysctl-8A2BE2?style=for-the-badge&logo=linux&logoColor=white)
![BBR](https://img.shields.io/badge/TCP%20BBR-8A2BE2?style=for-the-badge&logoColor=white)

Тюнинг параметров ядра Linux для повышения скорости и стабильности соединений: TCP Window Scaling, алгоритм BBR, настройка сетевых буферов — готовый профиль: [Optimized-sysctl-for-VPN-nodes](https://github.com/KimberlyWay/Optimized-sysctl-for-VPN-nodes).

### Инфраструктура и CDN Cloudflare
![Cloudflare](https://img.shields.io/badge/Cloudflare%20DNS%20%2F%20CDN-8A2BE2?style=for-the-badge&logo=cloudflare&logoColor=white)
![Tunnel](https://img.shields.io/badge/Cloudflare%20Tunnel-8A2BE2?style=for-the-badge&logo=cloudflare&logoColor=white)

Управление DNS-записями, проксирование трафика и использование Cloudflare Tunnel (Zero Trust) для публикации сервисов без открытия портов наружу. Настройка CDN и кэширования (Cache Rules, Page Rules) для ускорения отдачи статики и снижения нагрузки на origin-сервер. Настройка WAF и правил безопасности на уровне Cloudflare.

Полный цикл работы с доменами: привязка к IP, автоматизация SSL-сертификатов (Certbot/Caddy). Настройка SMTP-шлюзов для отправки почты и уведомлений с сервера.

### Безопасность (Hardening)
